# Mukesh Kumar portfolio

Personal portfolio built with Next.js App Router, React, Tailwind CSS, Three.js, and GSAP.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run build
```

## Project structure

- `src/app` — route, page metadata, and global styles
- `src/components` — navigation, project cards, WebGL scene, and motion
- `src/data/portfolio.ts` — project, capability, and toolbox content
- `public/mukeshbeyond.png` — supplied profile image
